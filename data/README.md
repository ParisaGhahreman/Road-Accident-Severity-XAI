# Data directory

Raw and processed datasets are intentionally excluded from version control.

- Place source files required by the notebooks under the following paths:
  - `data/raw/UK/dft-road-casualty-statistics-collision-2025.csv`
  - `data/raw/UK/dft-road-casualty-statistics-vehicle-2025.csv`
  - `data/raw/UK/dft-road-casualty-statistics-casualty-2025.csv`
  - `data/raw/UK/dft-road-casualty-statistics-road-safety-open-dataset-data-guide-2025.xlsx`
  - `data/raw/France/caract-2024.csv`, `lieux-2024.csv`, `vehicules-2024.csv`, and `usagers-2024.csv`
  - `data/raw/Ethiopia/Addis_Ababa_city_RTA.csv`
- Harmonized outputs are written to `data/processed/`.
- Do not commit source datasets unless their licenses explicitly permit redistribution.

Exact dataset citations and download locations should be documented in `DATA_SOURCES.md` before public release.
